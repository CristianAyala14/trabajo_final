# Documentación del sistema

[Volver al README principal](../README.md)

Esta documentación define el alcance objetivo del MVP. Las funcionalidades descritas no deben interpretarse como completamente implementadas; su situación se aclara en Estado y trazabilidad.

| Documento | Contenido |
|---|---|
| [Presentación y alcance](alcance.md) | Problema, objetivos, funciones incluidas y ampliaciones futuras. |
| [Módulos](modulos.md) | Propósito, funciones, entradas y resultados de cada módulo. |
| [Requisitos funcionales](requisitos-funcionales.md) | RF01 a RF16 con criterios de aceptación. |
| [Requisitos no funcionales](requisitos-no-funcionales.md) | RNF01 a RNF12 con criterios de verificación. |
| [Reglas de negocio](reglas-de-negocio.md) | RN01 a RN14 y dónde se controla cada regla. |
| [Base de datos](base-de-datos.md) | Entidades, relaciones, diccionario, restricciones e índices. |
| [Procesos y cálculos](procesos-y-calculos.md) | Neteo, alícuotas, vistas y criterios temporales. |
| [Historias y casos de uso](casos-de-uso.md) | Objetivos del operador y recorridos de interacción. |
| [Arquitectura](arquitectura.md) | Tecnologías y responsabilidades de las capas. |
| [Estado y trazabilidad](estado-y-trazabilidad.md) | Relación entre requisitos y componentes y estado documentado. |
| [Glosario](glosario.md) | Términos utilizados en el sistema. |
| [Diagrama entidad-relación](diagramas/entidad-relacion.md) | Estructura de datos y cardinalidades. |
| [Diagrama de clases](diagramas/clases.md) | Atributos, comportamiento, asociaciones y servicios propuestos. |

Los diagramas están escritos en Mermaid. Los archivos `.mmd` de la carpeta `diagramas` permiten editarlos en herramientas compatibles. Los requisitos conservan sus identificadores para que puedan citarse desde los módulos, casos de uso y pruebas.
